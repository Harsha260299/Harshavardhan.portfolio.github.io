## 💡 Customization Tips

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-bg: #0a0e27;
    --accent-blue: #4da3ff;
    --accent-purple: #9d50ff;
    --accent-cyan: #00d9ff;
}
```

### Animation Speed
Adjust transition durations in CSS:
```css
transition: all 0.3s ease;
```

### Particle Count
Modify in `script.js`:
```javascript
const particleCount = 30; // Increase or decrease
```
